# SaveTinker editors

Editors for [SaveTinker](https://github.com/mrissaoussama/SaveTinker).

| Editor | Console |
|---|---|
| Mario Kart 7 | 3DS |
| Kid Icarus: Uprising | 3DS |
| Super Kirby Clash | Switch |
| Hyrule Warriors: Age of Calamity | Switch |
| JSON Save Editor | Any game with JSON saves |
| Unreal Save Editor | Unreal Engine 4 and 5 games |
| RPG Maker MV/MZ Save Editor | RPG Maker MV and MZ games (`.rpgsave`, `.rmmzsave`) |

The game editors are ports of Marc Robledo's [savegame-editors](https://github.com/marcrobledo/savegame-editors)
(MIT, see `LICENSE-savegame-editors`).

Repository URL:

```
https://raw.githubusercontent.com/mrissaoussama/savetinker-editors/main/repo/repo.json
```

Update with `savetinker-cli pack editors repo`.
